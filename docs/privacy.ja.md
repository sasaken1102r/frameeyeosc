# プライバシー

[README に戻る](../README.ja.md)

- 視線とまぶたの値（目のカメラを使っていれば、目を細めた動きと瞳孔の大きさも）は、あなたが決めた送り先にだけ送ります: 上の送り先、LiveLink モードで目のカメラを使っているときは瞳孔のために同じ PC のもう 1 か所、VRChat のポート 9000（状態ファイルの `pupil_target`）、それに足した[ほかのアプリ](outputs.ja.md#ほかのアプリ)です。パネルの左の列に送り先がすべて出ます。テレメトリはなく、インターネットにも接続しません
- 目のデータは個人的なものです。どこを見たか、まばたきや瞳孔の変わり方から、何に気を取られたか、それにどう反応したか（興奮や疲れ）がわかることがあり、人を見分ける手がかりにもなります。信頼できるアプリにだけ送ってください
- `lan_only` がオン（既定）なら、目のデータは家のネットワークの中の住所（と、VPN と表示する 100.64〜127.x）にしか送りません。公開の住所には送らず、パネルに出します。`--no-extras` を付ければ、設定に何が書いてあっても、ほかのアプリには送りません
- パネルは、起動時と 1 時間に 1 回、GitHub（`api.github.com`）に最新のリリースを問い合わせます（「新しい版の確認」がオフなら問い合わせません）。ふつうの Web アクセスと同じく、GitHub には IP アドレスが見えます。ほかには何も送らず、ダウンロードも GitHub からだけです。送り方タブの FrameEyeOSC モジュールのアドレスは、押したときだけ Frame のブラウザーで GitHub のページを開きます
- 新しい版の確認がオンのとき、frame.sasaken1102s.net からアプリの一覧とアイコンを取ってきます（起動時と、「詳細」›「バージョン」からその一覧を開いたとき。私のほかのアプリと合わせて 1 時間に 1 回まで。`~/.cache/frame-apps/` に置きます）。オフなら、前に取った一覧かパネルに入っている一覧を出します。入っているか・動いているかは、ホームフォルダの中のファイルと `systemctl --user` で調べるだけで、何も送りません。［入れる］は、実行するコマンドを見せてから Konsole でインストーラーを開きます
- ディスクに書くもの:
  - 設定（`~/.config/frameeyeosc/config.json`）と、左右それぞれの目の「普段の開き具合」の学習値2つ（`~/.config/frameeyeosc/calibration`）
  - `install.sh` が置くもの: 更新のスクリプト `~/.local/share/frameeyeosc/frame-update.sh`、パネルの更新履歴が読む変更履歴（同じ場所の `CHANGELOG.md`・`CHANGELOG.ja.md`）、インストールのオプション `~/.config/frameeyeosc/install-args`
  - 更新の確認と更新が `~/.cache/frameeyeosc/` に書くもの: `update-check.json`（GitHub の前回の答え）、`update-state.json`（前回の更新の進み具合）、`update.log`（前回の更新のログ）、作業フォルダ `update/`（毎回空にします。写した更新のスクリプトだけ残ります）、確認や更新の最中だけの `update.lock/` フォルダ

  - パネルが `$XDG_RUNTIME_DIR/frameeyeosc/` に書くもの（メモリの上にあり、再起動で消える）: 目を合わせるときの音のファイル `sounds/`（起動時に書く）
  - パネルが `~/.local/state/frameeyeosc/` に書くもの: 校正と目合わせの記録 `reports/`（新しい 10 件。[パネル](panel.ja.md#パネル)を参照）と、`panel.json`（詳細タブ・まぶたタブ・視線タブで最後に開いたページ、視線の倍率の鍵、直近 5 回の全部合わせの上の幅）。記録を作るときは、その前後のジャーナル（`journalctl --user`、読むだけ）と Valve の `~/.local/share/Steam/logs/eyetracking.txt` を読みます
  - eyecam（目のカメラ）が書くもの: 設定と校正 `~/.config/eyecam/`（`settings.json` に見開きの感度、`calib.json` に校正で測った値）、メモリの上（再起動で消える）の決まった場所: `/run/user/1000/eyecam/` に状態ファイル・操作用のソケット・frameeyeosc が読む目の値（と、パネルの目のプレビューでカメラ映像を出している間だけ、その映像。下を参照）、そのフォルダーの隣に eyecam-grab がバッファを渡すソケット `/run/user/1000/eyecam.sock`。systemd のジャーナル（`journalctl --user -u eyecam`）に、30 秒ごとに 1 行（処理したフレームの数、1 フレームの時間、左右の瞳孔のふだんの差）と、校正のたびに測った値の報告。校正では目の映像を残しません（開発者モードを除く）。校正のたびに（準備のときもあとからも、失敗したり止めたりしても）、`~/eyecam/calib_YYYY-MM-DD_HH-MM-SS/` に小さなテキストのファイルだけ（1 MB ほど: 結果、フレームごとに出した値、フレームの時刻、Valve の値）を残します。eyecam の開発者モード（`~/.config/eyecam/settings.json` の `"dev": true`。手で書き換えるもので、最初はオフ）のときだけ、その 18 秒の目のカメラの映像も残します（1 回で約 0.5 GB）。詳細タブの開発用の「目の撮影」は、いつも目の映像を `~/eyecam/rec_YYYY-MM-DD_HH-MM-SS/` に残します（1 回で約 2.5 GB。始める前にパネルにも出ます）。詳細タブの「細めの学習用に撮る」は、最初の画面で同意したときだけ、録画（目の映像。1 本 約 2.7 GB）を `~/eyecam/contrib/` に、そのときの校正と eyecam の設定の写し、`info.txt`（アプリの版・時刻・そのときの設定・眼鏡やインサートの答え・録画のあいだに HMD を外したか・フォルダ名・大きさ。個人の情報は入れない）と、録画ごとの校正結果の写し、まとめた 1 つのファイルと一緒に残します。パネルはどれもどこにも送りません（渡すかはあなたが決めます。公開の場所には上げないでください）。［録画を消す］でフォルダごと消せます。目のカメラを使っていてパネルの目のログを記録している間（[開発](development.ja.md#開発)を参照）と、自分で eyecam に `driftlog on` を送ったとき（調べもの用）だけ、記録が終わるか `driftlog off` まで、数字だけ（映像なし）を `~/eyecam/drift/` に書きます（目のログと一緒なら `eyes_YYYY-MM-DD_HH-MM-SS.eyecam.csv`、手で送ったら `drift_YYYY-MM-DD_HH-MM-SS.csv`）: 目ごとに 1 秒 1 行（瞳を見つけた位置、比べている基準の値、出した値、Valve の開き具合と視線の上下。1 時間で約 1.3 MB、1 ファイル 50 MB まで）。どれもヘッドセットの外には出しません。要らなくなったら消してください

  上の eyecam の校正のファイル・録画・ドリフトの記録・ジャーナルの行と、パネルの記録（その `status.jsonl` には、校正や目合わせの間 1 秒ごとの本体と eyecam の状態が目の値ごと入ります）のほかは、目のデータは保存しません。ただし目を合わせたときに測った値（視線の平均の向きとばらつき、目ごとの開き具合の平均）は、1 回ごとに 1 行 systemd のジャーナルに残り、まぶたの読んだ値は `config.json` に残ります。最新の目の値は状態ファイルにありますが、これはメモリの上にあって本人しか読めず、1 秒に 10 回上書きされます。履歴は残しません
- 送るのは暗号化しないただの UDP で、家のネットワークで使う前提です。同じネットワーク上のほかの機器から読める可能性があります
- 「視線の点を表示」がオンの間と、目のプレビューを開いている間は、送っている視線（プレビューには目ごとのまぶた・細め・瞳孔の、送る値・Valve の値・目のカメラの値も）を Unix ソケット（状態ファイルのフォルダの `gaze-dots.sock`）でパネルにも渡します。本体が送るのは、パネルがそのソケットを開いている間だけです。ヘッドセットの外には出ず、保存もしません
- 目のプレビューのカメラ映像: プレビューを開いていて「カメラ映像」がオンの間だけ、パネルが 1 秒ごとに eyecam に頼み、eyecam は目ごとの小さな灰色の映像（200×200、毎秒 15 枚ほど）と見つけたものを `/run/user/1000/eyecam/preview` に書きます。メモリの上（tmpfs。ほかの場所には書きません）にあり、本人しか読めず（0600）、その場で上書きします。パネルが頼まなくなると（プレビューを閉じた・スイッチをオフにした・ダッシュボードを閉じた・パネルが落ちた）、eyecam は 3 秒ほどで止め、映像を 0 で消してからファイルを消します。パネルは読み取り専用で開いて描くだけで、映像を保存も記録もせず、どこにも送りません
