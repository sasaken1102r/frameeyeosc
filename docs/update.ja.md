# インストールと更新・前の版に戻す

[README に戻る](../README.ja.md)

インストールの手順は、README の[インストール](../README.ja.md#インストール)にあります。

## 入る場所

sudo は要りません。全部ホームフォルダ（`~/.local/bin`、`~/.local/lib/eyecam`、`~/.config`、`~/.local/share`）に入るので、SteamOS を更新しても消えません。更新するときも同じコマンドです。`--with-panel` を付けないときは、入っているパネルはそのまま残ります。

リリースには目のカメラの道具 eyecam も入っていて、`~/.local/lib/eyecam` に入ります。初めて入れたときに、ユーザーサービス（`eyecam.service`）として有効にして動かします。更新では、動いていれば再起動するだけで、自分でオフにしたものはオフのままにします（[止める・取り除く](eyecam.ja.md#止める取り除く)）。パネルで目のカメラの準備をするまでは待っているだけで、何も変わりません（[目のカメラ](eyecam.ja.md#目のカメラ)）。sudo がいるかもしれないのはその準備の 1 回だけで（ふつうは要りません）、それも自分で実行します。`install.sh` が sudo を使うことはありません。

## 0.4.0 より前の版から更新するとき

0.4.0 より前の版には更新の仕組みがないので、0.4.0 へは一度だけ手で更新します。新しい tar.gz を上と同じ手順でコピーして広げ、`./install.sh --with-panel`（パネルがいらなければ `./install.sh`）を実行するだけです。`~/.config/frameeyeosc/env` と学習したまぶたの値はそのまま使われ、サービスも新しい版で起動し直します。

`env` の `FRAMEEYEOSC_ARGS` に書いたオプションは、今までどおり効きます。ただし、そこに書いた項目はパネルでは「コマンドで固定中」になって変えられません。パネルで変えたい項目は `env` から消して、`systemctl --user restart frameeyeosc` してください（値はパネルで設定し直します）。

削除は `./install.sh --uninstall`（パネルも消えます。設定と学習値も消すなら `--purge` を付ける）。

## パネルから更新する（0.4.0 から）

0.4.0 からは、パネルの「更新する」で更新できます。パネルの「詳細」タブの「バージョン」に、入っている版が出ます。パネルは起動時と、その後 1 時間に 1 回、GitHub に新しい版がないか確かめます。「今すぐ確かめる」を押すとその場で確かめます。新しい版があれば、「バージョン」の版の下の箱にその版の要約が出ます（日本語の要約があるリリースなら、日本語の画面ではそちら）。左の列にもお知らせが出て、押すとこのページが開きます。「更新する」で、ダウンロードしてリリースの `SHA256SUMS` と照らし合わせ、前回と同じオプション（`~/.config/frameeyeosc/install-args` に残っています）でその `install.sh` を実行します。本体とパネルは新しい版で起動し直します。`install.sh` を実行する前に失敗したときは何も変わりません。ログは `~/.cache/frameeyeosc/update.log` です。1 時間ごとの確認は「新しい版の確認」をオフにすると止まります（「今すぐ確かめる」は使えます）。更新そのものは、ボタンを押したときにしか行いません。

### テスト版

みんな向けの新しい版の前に、試してくれる人向けのテスト版（`0.7.11-beta.1` など）を出すことがあります。受け取るには、「バージョン」の「テスト版も受け取る」をオンにしてください（最初はオフ。設定は `~/.local/state/frameeyeosc/panel.json` に残ります）。新しい版の確認でテスト版も出るようになり、「新しいテスト版 … があります」と分かるように出ます。更新のしかたは上と同じです。オフのあいだは、今より新しいテスト版があると、その横に小さく「テスト版あり」と出ます。オンにして「更新する」を押さない限り、何も入りません。

戻すときは「テスト版も受け取る」をオフにします。オフにしても今のテスト版はそのままです。本番の版の最新が今のテスト版より古いときは、「バージョン」に「本番の版 … に戻せます」と「戻す」が出ます。押すと確かめてから、更新と同じしかたでその本番の版を入れます（左の列のお知らせは出しません）。戻さなければ、本番の版が出たとき（`0.7.11-beta.2` のあとの `0.7.11` など）にいつもどおり届きます。0.8.1-beta.1 までのテスト版にはこの「戻す」がないので、すぐ戻したいときは上の手順でリリースページから手で入れてください。

`SHA256SUMS` は同じリリースに付いているチェックサムで、署名ではありません。ダウンロードが壊れていたり途中で切れていたりするのは見つけられますが、GitHub 上でリリースごと差し替えられたものは見つけられません（チェックサムも一緒に差し替わるため）。

## 前の版に戻す

0.10 では、前の版にあった 2 つをなくしました: ETVR モード（VRCFaceTracking の ETVR Tracking Module に送るモード。見開きは LiveLink と FrameEyeOSC のモードでも伝わります）と、0.7.5 までの目の動かし方（v1。`eye_behavior` を 1。0.7.6〜0.9.x ではパネルの「詳細」›「バージョン」で切り替えられました）。今までの設定はそのまま使えます: `"output": "etvr"`（や `--output etvr`）は VRChat に送り、設定ファイルで一緒に `port` を 8889 にしていたら VRChat の 9000 番に戻します（コマンドラインで指定したポートはそのまま）。`eye_behavior`（や `--eye-behavior`）は読みますが何もしません。`"etvr"` と `eye_behavior` 1 のときは frameeyeosc がログに 1 行書き、パネルが設定ファイルを新しい値に書き直します。ETVR から LiveLink か FrameEyeOSC のモードに移るときは、VRCFaceTracking の ETVR Tracking Module を止めてください。

どちらかがどうしても要るときは、0.9 の最後の版を入れ直してください（下は 0.9.1。Releases にもっと新しい 0.9.x があれば、その番号に読み替えてください）:

1. GitHub の [Releases](https://github.com/sasaken1102r/frameeyeosc/releases/tag/v0.9.1) から、戻したい版の `frameeyeosc-0.9.1-steamframe-aarch64.tar.gz` と `SHA256SUMS` を Frame にダウンロードする
2. Konsole で、入れる前の設定を残しておく
   ```sh
   cp -a ~/.config/frameeyeosc ~/frameeyeosc-config-0.10
   cp -a ~/.config/eyecam ~/eyecam-config-0.10
   ```
3. 展開して入れる（tar.gz の中は `frameeyeosc` フォルダーです）
   ```sh
   sha256sum -c SHA256SUMS
   tar xzf frameeyeosc-0.9.1-steamframe-aarch64.tar.gz
   cd frameeyeosc && ./install.sh --with-panel
   ```
4. 0.10 のパネルが設定ファイルをもう新しい値に書き直しているので、戻した版のパネルで ETVR か v1（「詳細」›「バージョン」）を選び直す

注意（0.7.x 以前まで戻すときだけ）：0.7.6 は目のカメラの左右の取り違えを直したので、`~/.config/eyecam/calib.json` を一度だけ新しい形に書き換えています。0.7.5 以前に戻すと、この校正が左右逆に読まれます。戻したら校正をやり直すか、0.7.6 が残した `calib.json.pre-anatomical` を `calib.json` に戻してください。目合わせの左右の正面も、0.7.6 で両目共通の 1 つにまとめています（前の版でもそのまま使えます）。0.7.7 はヘッドセットの傾きを 0 に、左右・下の幅を 1 に一度だけ戻しています。前の版はその値のまま使うので、測り直したいときは戻した版でもう一度合わせてください。

また新しい版にするときは、パネルの更新ボタンか、いつものインストールのコマンドでどうぞ。
